HOW TO OPEN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge, or Firefox.

IMAGES
The website now uses local image assets cropped from the generated DRON Group visual reference, including the same seven sector-card images, hero/team visual, and supporting section imagery. Images work offline because they are included in assets/.

NOTES
